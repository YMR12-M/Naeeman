# نعيمًا — لوحة المحل

`client/`، React 18 + Vite + TanStack Query، بهوية «صالون زمان» وثيمين (نهار وليل). نفس اللوحة بتشتغل في المتصفّح وجوّه برنامج الكمبيوتر.

## الأدوار والصلاحيات (`server/src/config/permissions.js`)
الصلاحية `مورد.إجراء`، والأدوار ثابتة في الكود (مفيش جدول أدوار يتلخبط).

| الدور | يقدر |
|---|---|
| **مالك** `owner` | كل حاجة: الإعدادات والمواعيد، والفريق، والأجهزة، والسجل |
| **مدير** `manager` | الطابور كله (ومنه التحريك لأي مكان)، والخدمات، والحلاقين، والتقارير |
| **استقبال** `cashier` | الطابور: زبون من الشارع، ووصل، وغيّر الحلاق، وزوّد خدمة، وألغِ، وما جاش، وكود استعادة لزبون، وحالة الحلاقين |

الحلاق مالوش حساب هنا: بيدخل على تابلت الكرسي باسمه وPIN من 4 أرقام. أوّل مالك بيتعمل من `npm run db:bootstrap`.

## الصفحات
| الصفحة | فيها |
|---|---|
| الدخول، ونسيت كلمة السر، وتغيير كلمة السر الإجباري | |
| **التجهيز لأوّل مرّة** | المواعيد (المقترح 12 الضهر لنص الليل) ← قايمة أسعار مقترحة يعدّلها أو يشيل منها ← الحلاقين بالكراسي والـ PIN ← ربط التلفزيون |
| **الطابور** (الرئيسية) | عمود لكل حلاق موجود (اللي على الكرسي بعدّاد، واللي طالبينه بالاسم)، وعمود «أي حد» بالحلاق المتوقّع جنب كل دور، والحلاقين «مش موجودين» تحت. «زبون من الشارع» و«زبون نسي كلمة السر»، ومفتاح «بياخد أدوار». كل دور ليه قايمة: وصل، غيّر الحلاق، زوّد خدمة، حرّك، واتساب، ما جاش، ألغِ. لايف بالـ SSE |
| **النهارده** | الإيراد، والأدوار بالحالة والمصدر، ومتوسّط الانتظار ومدّة الخدمة، ولكل حلاق ولكل خدمة |
| **قايمة الأسعار** | الخدمات بالسعر والمدّة الافتراضية، والترتيب، والإيقاف |
| **الحلاقين** | الكرسي، والـ PIN، والحالة، والمدّة المتعلّمة لكل خدمة |
| **الأجهزة** | «اربط جهاز» ← كود من 6 أرقام صالح 10 دقايق، والأجهزة المربوطة وآخر ظهور، والإلغاء |
| **الإعدادات** | قواعد الطابور، والمواعيد (فترات بتعدّي نص الليل مسموحة)، وبيانات المحل، ورابط الزباين |
| **الفريق** | موظفين بإيميل ودور، وكلمة مؤقّتة |
| **السجل** | مين عمل إيه وإمتى (الأسعار، والفريق، والإعدادات، والأجهزة، وتحريك الطابور، وأكواد الاستعادة) |

## تفاصيل مهمّة
- **الجلسة:** توكن الدخول في الذاكرة بس، والتجديد في كوكي httpOnly (أو مخزن مشفّر في برنامج الكمبيوتر). تبويبين بيجدّدوا في نفس اللحظة: التاني بيستنى ويعيد (السيرفر بيدّي 10 ثواني سماح).
- **الأفعال على الطابور** بمفتاح منع تكرار ومحاولة تانية لو النت قطع.
- **القوايم المنسدلة** بتترسم برّه أعمدة الطابور (عشان ما تتقصّش) وبتفتح لفوق لو مفيش مكان.
