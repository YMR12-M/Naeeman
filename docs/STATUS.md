# نعيمًا — حالة الشغل

آخر تحديث: 2026-10-22. الخطّة الكاملة في [`PLAN.md`](PLAN.md)، والهوية في [`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md).

## اللي خلص

### السيرفر (`server/`) — الخطوتين 1 و2 من ترتيب البناء
**113 اختبار ناجح** (`npm test`)، اتشغّلوا 3 مرّات ورا بعض من غير ما حاجة تقع.

- **الأساس (منقول من نُزُل ومتعدّل):** فحص البيئة عند الإقلاع، وmigrations، ومصادقة الموظفين (JWT قصير + refresh دوّار + كشف السرقة + قفل الحساب + استعادة كلمة المرور بالبريد)، والصلاحيات (`owner` / `manager` / `cashier`)، وسجل التدقيق، وصندوق الإشعارات (بريد + Web Push)، والمهام الخلفية بقفل MySQL.
- **المحل:** البيانات، والمواعيد (فترات بتعدّي نص الليل، و24 ساعة، وأكتر من فترة في اليوم)، وقواعد الطابور، و«فاتح دلوقتي؟». يوم الشغل في محل بيقفل 2 بالليل بيتحسب على يوم بداية الوردية.
- **قايمة الأسعار والحلاقين:** إضافة جماعية للتجهيز لأوّل مرّة، وترتيب، وأرشفة بدل المسح، ورقم كرسي ما يتكرّرش، وPIN بيتخزّن bcrypt بس، وحالة الحلاق (متاح / استراحة لمدّة / مش موجود).
- **نواة الطابور:**
  - `src/queue/engine.js`: دوال صافية (الوقت المتوقّع، «قدّامك كام»، مين الجاي، «أخّرني»، أرقام الترتيب، تعلّم المدّة). عليها اختبارات لوحدها.
  - `src/queue/states.js`: الانتقالات المسموحة لكل نوع مستخدم.
  - `src/modules/queue/queue.service.js`: كل تعديل تحت قفل صفّ `shop_state` للمحل، وبيطبّق المهل اللي خلصت قبل ما يتنفّذ، وبعده بيبعت «قرّب دورك» ويزوّد رقم النسخة.
  - العمليات: زبون من الشارع، و«التالي»، و«خلّصت»، ووصل، وإلغاء (اللي على الكرسي محتاج سبب)، وما جاش، وتحريك يدوي بسبب (بيتسجّل)، وتغيير الحلاق، وزيادة خدمة، و«أخّرني»، و«جاي».
  - المهل: اتنادى وما وصلش ← يتأخّر خطوتين ← ما جاش. زبون غاب مرّتين ولازم يأكّد وما أكّدش ← اتلغى. أدوار يوم خلص ← اتلغت.
  - قواعد أخد الدور من التطبيق (جاهزة في الخدمة، ومتختبرة بنداء مباشر لحد ما مسارات الزبون تتعمل): المحل موقّف أو قافل، والأدوار عن بُعد مقفولة، ودور واحد شغّال لكل زبون (بقفل على الزبون)، وحدّ اليوم، ومفيش حلاقين، والوقت المتوقّع قريب من القفل.
  - الإشعارات للزبون: «دورك جه»، و«قرّب دورك» (مرّة واحدة)، و«اتأخّرت خطوتين»، و«الدور اتلغى»، و«نعيمًا» لما يخلص.
  - التحديث اللحظي: `GET /queue/stream` (SSE، بيتقفل لما التوكن يخلص)، والاحتياطي `GET /queue?since=`.
  - `Idempotency-Key` على كل الأفعال: المحاولة المكرّرة بترجع نفس الرد من غير ما تتنفّذ.
  - اختبار سباق: 8 حلاقين بيدوسوا «التالي» في نفس اللحظة، وكل زبون بيروح لحلاق واحد بالظبط.
- **اتجرّب فعلًا:** السيرفر قام على قاعدة مؤقتة (`naeeman_smoke`، اتمسحت بعدها)، والدخول والطابور ردّوا صح.

### التصميم
`docs/DESIGN_SYSTEM.md` («صالون زمان»)، واللوجو والأيقونات في `brand/`.

## التشغيل

```bash
cd server
cp .env.example .env        # وعدّل القيم
npm install
npm run db:setup            # ينشئ قاعدة naeeman ويعمل المحل والمالك من قيم .env
npm run dev                 # http://localhost:4030/api/v1
npm test                    # على قاعدة naeeman_test (بتتمسح بياناتها)
```

- MySQL المحلي: `root` من غير كلمة سر. قاعدة `naeeman` لسه ما اتعملتش (مفيش بيانات تجريبية). قاعدة `naeeman_test` بتتعمل لوحدها مع الاختبارات.
- البورتات: السيرفر 4030، لوحة المحل 5200، تطبيق الزبون 5201.

## الجاي (بالترتيب)
3. **حسابات الزبون:** `customer-auth` (تسجيل ودخول برقم الموبايل وكلمة سر، توكنات منفصلة بـ audience `naeeman-customer`)، ومسارات `/me` (أخد دور، دوري، «جاي»، «أخّرني»، إلغاء، check-in، السجل، `/me/stream`)، واشتراكات Web Push للزبون (جدول `push_subscriptions` بـ `customer_id`، والإرسال جاهز في `services/notifications/push.js`)، وصفحة المحل العامة `/public/shop`.
4. **الأجهزة:** كود الربط، وتوكن الجهاز (`X-Device-Token`)، وشاشة التلفزيون (`/display`) بالكود المتغيّر للـ check-in (HMAC بـ `shops.checkin_secret`)، والكشك (`/kiosk`)، وتابلت الكرسي (`/chair` بالـ PIN، وقفل بعد محاولات فاشلة؛ الأعمدة `failed_pins` و`pin_locked_until` موجودة).
5. **ملخّص اليوم** (`/reports/today`).
6. الواجهات: `client/`، و`mobile/`، و`desktop/`.

## ملاحظات للي هيكمّل
- اكتب بنفس أسلوب الموجود: تعليقات عربية، ESM، Zod، ردود `{success, data}`، المال بالقروش، و`withQueue` لأي تعديل على الطابور (ما تعدّلش `queue_tickets` من برّه الخدمة).
- أي تغيير بيأثّر على الوقت المتوقّع من برّه الطابور (زي حالة حلاق) لازم ينادي `queueService.touch(shopId)`.
- ملفات الـ migrations اللي اتنفّذت ما تتعدّلش؛ أي تغيير = ملف جديد.
- الـ bus جوّه نفس العملية: لو السيرفر اتشغّل بأكتر من نسخة، الشاشات بتعتمد على `?since=` لحد ما يتحطّ Redis pub/sub في `src/queue/bus.js`.
