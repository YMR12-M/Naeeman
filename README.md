# نعيمًا

محل الحلاقة من غير قعدة الانتظار. الزبون ياخد دوره من الموبايل أو من تابلت على باب المحل، ويعرف قدّامه كام وهيستنى قد إيه، ويوصله إشعار لما دوره يقرّب. والحلاق شغله كله زرار واحد: «التالي».

## فيه إيه

| الجزء | لمين | فيه |
|---|---|---|
| **لوحة المحل** (`client/`) | المالك والمدير والاستقبال | التجهيز لأوّل مرّة، والطابور لايف (عمود لكل حلاق و«أي حد»)، وزبون من الشارع، والنهارده، وقايمة الأسعار، والحلاقين، والأجهزة، والإعدادات، والفريق، والسجل، و**الكاشير** (دفع بطرق متعدّدة، ودرج، وتقفيل يوم، وإيصال)، و**المنتجات والمخزن**، و**حساب الحلاقين**، و**الزباين** (كارت فيه ملاحظات وصور قصّات وأختام) |
| **شاشة التلفزيون** (`/display`) | الزباين في المحل | اللي على كل كرسي، والخمسة الجايين، والانتظار دلوقتي، وQR لأخد دور، وكود «وصلت» بيتغيّر كل دقيقة |
| **تابلت الباب** (`/kiosk`) | الزبون اللي داخل من الشارع | خدمة ← حلاق ← اسم، ورقم كبير في الآخر |
| **تابلت الكرسي** (`/chair`) | الحلاق | دخول بالـ PIN، وزرار «التالي» ماسك نص الشاشة، و«خلّصت»، و«+ خدمة»، والاستراحة، وكارت الزبون (ملاحظاته وآخر قصّة) و«صوّر القصّة» |
| **تطبيق الزبون** (`mobile/`، PWA) | الزبون من البيت | صفحة المحل العامة، وخُد دور، و«دوري» لايف، و«جاي» و«أخّرني»، و«وصلت» بالـ QR، والسجل والفاتورة، والإشعارات، وكارت الأختام، و«قصّاتي» |
| **السيرفر** (`server/`) | الكل | الطابور (الحالات، والوقت المتوقّع، والمهل)، والحسابات، والأجهزة، والإشعارات، والتقارير، والفواتير والمخزن والحساب والكروت، والنسخ الاحتياطية |
| **برنامج الكمبيوتر** (`desktop/`) | كمبيوتر المحل | اللوحة، والتلفزيون على الشاشة التانية لوحده، وطباعة الإيصال، وممكن يبقى **هو سيرفر المحل** (MySQL والسيرفر جواه، والأجهزة على واي فاي المحل من غير ما النت يفرق) |

الهوية البصرية «صالون زمان» (الحيطة النعناعي، والمرايات، واليافطة، وجلد الكرسي) في [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md).

## الهيكل

```
Naeeman/
├── server/     Node 22 + Express + MySQL — بادئة المسارات /api/v1، وفحص الصحّة /health
├── client/     React 18 + Vite — لوحة المحل وشاشات الأجهزة (بورت 5200)
├── mobile/     React 18 + Vite — تطبيق الزبون PWA (بورت 5201)
├── desktop/    Electron — اللوحة على كمبيوتر المحل، وممكن يشغّل السيرفر والقاعدة (وضع المحل)
├── brand/      اللوجو والأيقونات
├── deploy/     nginx وملف البيئة لـ docker compose
├── docs/       الخطة، والحالة، والهوية، وتوثيق كل نظام
├── docker-compose.yml · render.yaml · .github/workflows/ci.yml
```

## التشغيل على جهازك

محتاج Node 22 وMySQL 8.

```bash
# 1) السيرفر
cd server
cp .env.example .env        # وعدّل القيم: قاعدة البيانات، وأوّل محل ومالك
npm install
npm run db:setup            # migrations + المحل والمالك من .env (مفيش بيانات تجريبية)
npm run dev                 # http://localhost:4030/api/v1

# 2) لوحة المحل (في تيرمنال تاني)
cd client && npm install && npm run dev      # http://localhost:5200

# 3) تطبيق الزبون (في تيرمنال تالت)
cd mobile && npm install && npm run dev      # http://localhost:5201
```

ادخل اللوحة بإيميل المالك، وهيفتح لك التجهيز لأوّل مرّة: المواعيد، وقايمة الأسعار، والحلاقين، وربط التلفزيون. الواجهتين بيوصّلوا `/api` للسيرفر من غير CORS (بروكسي Vite)، فتقدر تفتحهم من موبايل أو تابلت على نفس الشبكة بعنوان الكمبيوتر.

## Docker

```bash
cp deploy/.env.example .env     # الأسرار، والعناوين، وأوّل مالك
docker compose up -d --build
```

ده بيشغّل MySQL والسيرفر والواجهتين على nginx: اللوحة على 5200، وتطبيق الزبون على 5201، والاتنين بيوصّلوا `/api` للسيرفر. السيرفر بيعمل الـ migrations وأوّل مالك لوحده عند كل تشغيل (آمن للتكرار). **في الإنتاج لازم HTTPS قدّامهم** (الكوكي الآمنة، وإشعارات المتصفّح، والكاميرا على الموبايل).

## Render

[`render.yaml`](render.yaml) فيه تلات خدمات: `naeeman-api` (Node، الخطة المجانية)، و`naeeman` (اللوحة، static)، و`naeeman-app` (تطبيق الزبون، static). الواجهتين بيوصّلوا `/api/*` للسيرفر. Render ما عندوش MySQL، فالسيرفر محتاج قاعدة من برّه (Aiven مثلًا) تتكتب بياناتها من الداشبورد (`DB_HOST` و`DB_PORT` و`DB_USER` و`DB_PASSWORD`، و`DB_SSL=true`).

## برنامج الكمبيوتر

```bash
cd desktop
npm install
npm start          # يبني اللوحة وتطبيق الزبون وينسخهم جوّه البرنامج ويفتحه
npm run dist       # ملف تثبيت (dmg / exe / AppImage) في desktop/release
```

أوّل تشغيل بيسأل: **«الكمبيوتر ده هو سيرفر المحل»** أو **«اتصل بسيرفر موجود»**.

- **سيرفر المحل:** بتكتب اسم المحل وبيانات المالك، وبتختار MySQL (متشحونة مع البرنامج على ويندوز، أو متسطّبة على الجهاز)، والبرنامج بيجهّز القاعدة ويشغّل السيرفر. التلفزيون والكشك وتابلت الكرسي بيفتحوا `http://<عنوان الكمبيوتر>:4030` (الروابط والـ QR في لوحة المحل ← الأجهزة)، وتطبيق الزبون على `:4031`، على واي فاي المحل. جوّه المحل كل حاجة شغّالة حتى لو النت قطع. النسخ الاحتياطية في `userData/hub/backups` (وبتتنسخ لفولدر Google Drive أو OneDrive لو اخترته من قايمة «نعيمًا»).
- **اتصال بسيرفر:** عنوان سيرفر على كمبيوتر تاني أو Render.
- **الطباعة:** من قايمة «نعيمًا» ← «طابعة الإيصالات» (أو «اسألني كل مرّة»).

لو فيه شاشة تانية متوصّلة (التلفزيون)، البرنامج بيفتح عليها شاشة التلفزيون ملء الشاشة لوحده. التفاصيل في [`docs/DEVICES_SYSTEM.md`](docs/DEVICES_SYSTEM.md)، وشحن MySQL داخل ملف ويندوز في [`desktop/vendor/README.md`](desktop/vendor/README.md).

## الاختبارات

```bash
cd server && npm test                    # 208 اختبار على قاعدة naeeman_test (بتتمسح)
cd client && npm test && npm run check:contrast
cd mobile && npm test && npm run check:contrast
cd desktop && npm test                    # وضع المحل: تشغيل حقيقي للسيرفر وMySQL
cd desktop && npm run build:client && npm run smoke:hub   # Electron من غير نافذة
```

GitHub Actions بيشغّل اختبارات السيرفر (مع MySQL) والواجهتين وبناءهم مع كل push. التفاصيل في [`docs/TESTING.md`](docs/TESTING.md).
